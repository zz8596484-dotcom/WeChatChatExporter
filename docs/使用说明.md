# 微信聊天采集助手 —— 使用说明

> 一款运行在 Android 手机本地、用于整理您本人微信账号中有权限查看的指定联系人聊天记录的助手。
> 所有数据只保存在手机本地，**不上传任何服务器**，不调用第三方云端服务。

## 1. 工具简介

本工具通过 **Android 无障碍服务（Accessibility Service）** 读取屏幕上的可访问文字，配合**自动缓慢滚动**、**去重**、**断点续采**等功能，将您在微信聊天窗口里能看到的内容，整理成规范的纯文本，导出为 Markdown 和 JSON 文件，便于后续交给 ChatGPT 等工具进行分析。

**它不会**：
- ✗ 破解微信数据库
- ✗ 读取微信私有加密文件
- ✗ 提取任何密钥
- ✗ 需要 Root
- ✗ Hook / 修改微信进程

**它只是**：模拟「人眼观看 + 手指上滑 + 抄写整理」的合法辅助工具。

## 2. 需要哪些权限

安装并首次运行时，请您按要求授权以下权限。权限均在合法框架内申请，用途明确：

| 权限 | 用途 | 申请时机 |
| --- | --- | --- |
| **无障碍服务** | 读取微信聊天界面的屏幕文字，判断消息气泡位置、获取时间、发送者，并执行自动上滑滚动 | 在系统中手动开启（见下文） |
| **悬浮窗权限**（SYSTEM_ALERT_WINDOW） | 显示可拖动的「悬浮球」控制按钮（开始 / 暂停 / 继续 / 结束导出） | 首次打开悬浮球时 |
| **通知权限**（POST_NOTIFICATIONS） | 显示前台服务常驻通知，保证采集进程正常运行 | 首次启动应用时 |
| **存储权限**（读写外部存储） | 将导出的 `chat_*.md` / `chat_*.json` 文件保存到手机指定目录 | Android 13（API 33）以上一般无需手动授予 |

> 说明：
> - 无障碍服务必须在手机**系统设置**里为「微信聊天采集助手」开启，不能在应用内一键开启。
> - 出于安全与隐私考虑，请仅在您本人设备上、整理您有权查看的记录时使用本工具。

## 3. 如何安装

本项目为标准的 **Android Studio / Gradle** 工程，建议用 Android Studio 打开编译。

1. **准备环境**：安装 Android Studio（建议最新稳定版），并确保本机有 Android SDK。
2. **打开工程**：用 Android Studio 打开项目根目录 `/sdcard/WeChatChatExporter`（或您拷贝到电脑上的该目录）。
3. **同步 Gradle**：首次打开会自动同步 Gradle 与依赖（可通过 `File → Sync Project with Gradle Files` 手动触发）。
   - 编译配置：`compileSdk 34`、`minSdk 24`、`targetSdk 34`。
   - 已声明依赖：AppCompat 1.6.1、Material 1.11.0、core 1.12.0。
   - 可选依赖：`tess-two 9.1.0`（本地离线 OCR 兜底，默认不启用）。
4. **编译 APK**：菜单 `Build → Build Bundle(s) / APK(s) → Build APK(s)`。
5. **安装到手机**：
   - 方式一：将生成的 APK（位于 `app/build/outputs/apk/debug/app-debug.apk`）传到手机，点击安装，并允许「安装未知来源应用」。
   - 方式二：用数据线连接手机，开启「USB 调试」，直接点击 Android Studio 的 Run 一键安装运行。
6. 安装完成后，桌面会出现应用图标 **「微信聊天采集助手」**。

## 4. 如何运行（首次设置）

请按以下顺序完成首次设置：

### 第 1 步：打开应用
点击桌面上的「微信聊天采集助手」图标，进入主界面。

### 第 2 步：开启无障碍服务
1. 打开手机 **系统设置**。
2. 找到「**无障碍 / 无障碍功能**」入口（不同品牌路径不同，如 vivo 为「设置 → 更多设置 → 无障碍」；可在系统设置搜索框输入「无障碍」快速找到）。
3. 选择「**已安装的服务**」→ 找到「**微信聊天采集助手**」→ 开启开关并**确认**。
   - 应用主界面也有「开启无障碍服务」按钮，点击后会提示并引导您前往系统设置开启。

### 第 3 步：授权存储与通知
- Android 13 及以上首次使用时，若系统提示通知权限，请允许。
- 如需保存导出文件，请确保应用拥有对外部存储的写入权限（Android 13 以上一般自动拥有专属存储，无需额外授权）。

### 第 4 步：如需悬浮球，授权悬浮窗
- 在主界面点击「开始采集」前，若未授权悬浮窗，会提示前往「悬浮窗权限」授予。授予后即可看到可拖动的悬浮球。

## 5. 如何指定保存目录

主界面有一个 **「保存目录」输入框**，默认值为：

```
/sdcard/WeChatChatExporter/output/
```

- 您可以手动改成任意您想要的目录，例如 `/sdcard/Download/chat` 或 `/storage/emulated/0/聊天记录`。
- 输入后，该目录会被记忆（保存到应用本地设置），下次打开仍保留。
- **采集结束后导出**时会自动使用您在此填写的目录。
- 若目录不存在，导出时会自动创建。

## 6. 如何开始采集

按以下步骤开始采集一份聊天记录：

1. **进入微信聊天窗口**：打开微信，进入您要采集的那个联系人的聊天界面（注意是**单独聊天**窗口）。
2. **返回应用到主界面**（或在微信内点开悬浮球控制面板）。
3. **填写联系人名（可选但推荐）**：在主界面「联系人」输入框填写联系人名字，例如「张三」。填写后导出的文件夹会以「联系人名_chat」命名，方便区分。
4. **点击「开始采集」按钮**：
   - 若无障碍服务未开启，会先引导您开启；
   - 开启后，应用会自动切换到微信聊天窗口（若已在窗口则直接开始），开始**缓慢向上滚动**并逐条读取屏幕上的聊天文字。
5. **无需人工干预**：工具会自动滚动、读取、判断左右气泡（左=对方、右=我）、提取时间、去重、按序保存。

> 提示：
> - 开始采集前请停留在目标聊天窗口顶部或中部；工具会从当前屏幕内容开始逐步向上翻。
> - 采集过程中请勿手动切换页面或下拉，以免遮挡屏幕内容。

## 7. 采集过程与悬浮球控制

采集过程中，您可以通过**悬浮球**或**主界面按钮**进行控制：

| 操作 | 悬浮球/主界面按钮 | 说明 |
| --- | --- | --- |
| **开始** | 「▶ 开始」 | 启动/继续采集 |
| **暂停** | 「⏸ 暂停」 | 暂停滚动与采集（可随时继续） |
| **继续** | 「▶ 继续」 | 从暂停处继续采集 |
| **结束并导出** | 「⏹ 结束导出」 | 结束采集，按时间排序并导出文件 |

**关于自动停止**：
- 当工具连续多轮滚动读取到的内容都重复（已到达聊天记录的顶部）时，会自动判定到顶并**暂停**，此时您可点击「结束导出」保存本次结果。
- 采集过程中如需中途保存，点击「结束导出」即可，已采集内容会正常导出并支持断点续采。

> 悬浮球可**拖动**到屏幕任意位置，单击可展开/收起控制面板。

## 8. 最终文件位置与格式

所有导出文件保存在您在主界面指定的目录（默认 `/sdcard/WeChatChatExporter/output/`）。

### 文件夹结构
检测到联系人名时，会生成形如 `张三_chat` 的文件夹；否则生成 `chat` 文件夹：

```
<保存目录>/
└── 张三_chat/          （或 chat/，无联系人名时）
    ├── chat_001.md
    ├── chat_001.json
    ├── chat_002.md      （消息超过 1000 条时自动分卷）
    ├── chat_002.json
    └── ...
```

### 分卷规则
- 每 **1000 条消息** 自动分为一卷：`chat_001`、`chat_002`……
- 消息会**按时间顺序**排序后写入（先按时间、再按发送者）。

### Markdown（chat_*.md）格式
采用表格形式，每行一条消息：

```
| 时间 | 发送者 | 类型 | 内容 |
| --- | --- | --- | --- |
| 2024-08-14 10:23 | 对方 | 文字 | 你好，我是张三 |
| 2024-08-14 10:24 | 我 | 文字 | 你好！请问... |
| 2024-08-14 10:25 | 对方 | 图片 | [图片] |
```

- **发送者**：`我`（右侧气泡） / `对方`（左侧气泡）
- **类型**：文字 / 图片 / 视频 / 语音 / 表情包 / 引用回复 / 转账 / 红包 / 撤回提示 / 系统消息 / 通话记录 / 文件 / 链接 / 位置 / 未知
- 内容中的换行会用 `<br>` 表示，竖线 `|` 会转义为 `\|`。

### JSON（chat_*.json）格式
```json
{
  "count": 1200,
  "exported_at": "2024-08-14 10:35:00",
  "messages": [
    {
      "time": "2024-08-14 10:23",
      "sender": "对方",
      "type": "文字",
      "content": "你好，我是张三"
    }
  ]
}
```

### 断点续采状态
- 每次采集的进度会保存在导出目录下的 `capture_state.json`（记录联系人、已完成消息数、最近指纹、保存时间）。
- 重新采集时会基于此状态自动去重续采，避免重复。

所有文件均以 **UTF-8** 编码保存，可直接交给 ChatGPT 等工具分析。

## 9. 常见问题（FAQ）

**Q1：为什么无法自动滚动 / 读取不到内容？**
- 请确认无障碍服务已开启，且当前停留在微信聊天窗口。
- 少数机型对无障碍的权限限制较严格，请检查「无障碍」设置中该服务的开关确实为开启状态。

**Q2：图片 / 视频 / 语音只显示占位文本？**
- 出于隐私与合规，工具默认只记录特殊消息的类型占位（如 `[图片]`、`[视频]`），不读取其内容。
- 若需识别图片文字，可自行开启本地离线 OCR（可选模块），仅在本机处理，不上传。

**Q3：能采集自己发的消息吗？**
- 能。右侧气泡识别为「我」，左侧识别为「对方」，均可采集。

**Q4：导出文件在哪？**
- 默认在 `/sdcard/WeChatChatExporter/output/`，也可通过主界面「保存目录」自定义。

**Q5：会联网上传数据吗？**
- **不会**。所有数据仅本地处理、本地保存，不上传任何服务器，也不调用第三方云端接口。

**Q6：遇到乱码或文件打不开？**
- 请确认文件为 UTF-8 编码，用支持 UTF-8 的文本编辑器（记事本选 UTF-8 / VSCode / Sublime）打开。
